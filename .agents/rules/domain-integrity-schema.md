# Domain Integrity, Freemarker & Schema.org Standards

## 1. Domain Models & Data Integrity
- **Card Data Contract:** Defined by [`CardData.java`](file:///src/main/java/de/maulmann/CardData.java) and [`CardJson.java`](file:///src/main/java/de/maulmann/CardJson.java).
- **Required Card Fields:** `id`, `player`, `year`, `set`, `brand`, `cardNumber`, `parallel`, `frontImage`, `backImage`.
- **Validation:** Always validate card JSON schema when importing or modifying card datasets.

## 2. Schema.org JSON-LD Structured Data
- Every card page must include a compliant `<script type="application/ld+json">` generated via [`CardSchemaGenerator.java`](file:///src/main/java/de/maulmann/CardSchemaGenerator.java).
- **Mandatory JSON-LD Fields:**
  - `@context`: `"https://schema.org"`
  - `@type`: `"ItemPage"` / `"IndividualProduct"`
  - `name`: Full formatted card title
  - `description`: Structured text including set, year, serial numbering, condition
  - `image`: Direct URLs to front and back AVIF card scans
- **Semantic Metadata:** Canonical `<link rel="canonical">`, OpenGraph tags (`og:title`, `og:image`, `og:description`), Twitter Card tags.

## 3. SEO & LLM Discovery Manifests
- Maintain [`llms.txt`](file:///llms.txt) and `llms-full.txt` standard index files for LLM/RAG crawlers.
- Ensure all static and dynamic card showcase pages are indexed in XML sub-sitemaps generated by [`SitemapGenerator.java`](file:///src/main/java/de/maulmann/SitemapGenerator.java).

## 4. Freemarker Template Safety
- Always use null-safe Freemarker operators: `${card.title!''}` or `<#if card.parallel??>`.
- Keep templates modular under `src/main/resources/templates/`.
