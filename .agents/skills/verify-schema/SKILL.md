# Verify Schema Skill

Use this skill to inspect and validate the JSON-LD structured data blocks generated on card showcase and collection pages.

## Verification Protocol

1. **Extract JSON-LD Block:**
   - In any target `.html` file under `output/`, locate the `<script type="application/ld+json">` block.

2. **Schema.org Validation Rules:**
   - **Type:** Must be valid schema entity (e.g. `ItemPage`, `Product`, `IndividualProduct`, `CollectionPage`, or `SportsCard`).
   - **Properties Required:**
     - `@context`: `"https://schema.org"`
     - `@type`: Entity type
     - `name`: Card / Collection title
     - `description`: Detailed card description with attributes (year, brand, set, parallel, serial number).
     - `image`: URL / path to card front and back images.
   - **Custom Properties:** Check that attributes generated by `CardSchemaGenerator.java` are properly embedded.

3. **Check OpenGraph and Canonical Meta Tags:**
   - Verify `<meta property="og:title">`, `<meta property="og:image">`, `<meta property="og:description">`.
   - Verify `<link rel="canonical" href="...">`.
